## 📌 Overview

This repository hosts the complete source code for **Dhruv Mandal's** personal portfolio. Engineered with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**, the application delivers a modern, high-performance web experience configured for static export (`output: 'export'`) and deployed to **Firebase Hosting**.

The portfolio serves as an interactive hub highlighting expertise in **Natural Language Processing (NLP)**, **Large Language Models (LLMs)**, **Retrieval-Augmented Generation (RAG)**, and **end-to-end Machine Learning pipelines**. Designed with an outcome-first philosophy, it showcases production-grade architectures that bridge theoretical data science and reliable software engineering.

## ⚡ Key Highlights & Features

- **🎯 Recruiter & Hiring Desk:** Purpose-built opportunity inquiry form with opportunity selection (*Full-time*, *Internships*, *Contract*, *Technical Chat*), 1-click email copy, real-time availability status, and direct CV download.
- **⚡ Static HTML Export Architecture:** Built with Next.js 15 App Router static generation (`output: 'export'`) for instant global delivery, zero cold starts, and minimal latency.
- **🧭 Dynamic ScrollSpy Navigation:** Custom scroll-aware navbar highlighting sections in real time (`#home`, `#skills`, `#about`, `#projects`, `#experience`, `#technical`, `#contact`) alongside a responsive mobile navigation drawer.
- **📂 Filterable Project Showcase:** Interactive portfolio grid with instant tag and category filtering across *Machine Learning*, *NLP*, *GenAI*, and *Web Apps*.
- **📊 Animated Impact Counters:** High-performance viewport-triggered counters utilizing Framer Motion's `useInView` and cubic ease-out `requestAnimationFrame` loops.
- **🎨 Distinctive Visual Identity:** Forest Green (`#1E392A`), Rich Gold (`#FFB800`), and Off-White (`#FDFDFD`) design palette with custom SVG organic shapes, rotated layered marquees, and Google Fonts (*Plus Jakarta Sans* & *Pacifico*).
- **📱 Fully Responsive & Accessible:** Fluid layouts tested across desktop, tablet, and mobile breakpoints with zero horizontal overflow and clean touch targets.
- **🌐 SEO & Social Graph Optimization:** Complete Open Graph and Twitter Card metadata with pre-configured canonical URLs, favicon suite, and rich snippets.

## 🚀 Getting Started

Follow these steps to set up the project locally for development or customization.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.18.0 or higher recommended, LTS 20+ preferred)
- [npm](https://www.npmjs.com/) (bundled with Node.js) or [pnpm](https://pnpm.io/)
- [Git](https://git-scm.com/)

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mandaldhruv/mandaldhruv.git
   cd mandaldhruv
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **View in your browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the live site with Hot Module Replacement (HMR).

## 📦 Build & Deployment

### Generating a Production Build

The application is configured for Next.js static HTML export (`output: 'export'`), producing a zero-dependency static build inside the `out/` directory:

```bash
# Build and export static assets to /out
npm run build
```

To test the exported build locally:
```bash
npx serve out
```

### Deploying to Firebase Hosting

The repository is configured via `firebase.json` to deploy the `out/` directory:

```json
{
  "hosting": {
    "public": "out",
    "ignore": [
      "firebase.json",
      "**/.*",
      "**/node_modules/**"
    ],
    "rewrites": [
      {
        "source": "**",
        "destination": "/index.html"
      }
    ]
  }
}
```

Deploy using the Firebase CLI:

```bash
# Install Firebase CLI if not already installed
npm install -g firebase-tools

# Login to Firebase
firebase login

# Deploy static export to Firebase Hosting
firebase deploy --only hosting
```
